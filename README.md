# To-Do List

A simple to-do list web app built with HTML, CSS and vanilla JavaScript.

## About

This is one of my early practice projects for learning front-end fundamentals — DOM manipulation, event handling and basic styling — without any frameworks or libraries.

## Features

- Add new tasks to the list
- Delete individual tasks using the delete button on each item

## How to Run

1. Clone this repository.
2. Open `to-do-list.htm` in any modern web browser.

No build step or server is needed.

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- `to-do-list.htm` — page markup
- `to-do-list.css` — styles
- `to-do-list.js` — app logic

## What I Learned

- Creating and removing DOM elements with JavaScript
- Handling click events on buttons
- Reading and clearing input field values
